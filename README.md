# dapper-keeper

Systems programmer · C and POSIX · notes in public

折腾中的小玩具

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/dapper-keeper.git
cd dapper-keeper
cargo build --release
```
